# Protótipos VagaNex

Esta pasta reúne os protótipos da plataforma VagaNex.

## Objetivo

Conectar empresas, oportunidades e profissionais, buscando maior compatibilidade entre as necessidades das empresas e as capacidades dos candidatos.

## Organização

Cada protótipo será armazenado em seu próprio arquivo, facilitando a evolução e a manutenção do projeto.

## Princípio

**Menos procura. Mais compatibilidade.**
